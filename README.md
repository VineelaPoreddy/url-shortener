# URL Shortener with Analytics

A production-style, scalable URL shortener built with FastAPI, PostgreSQL, and Redis.

## Status
🚧 Work in progress — currently in initial setup.

## Progress
- Basic FastAPI app with a working /health endpoint

## Local Setup
- Requires PostgreSQL (installed via Homebrew: `brew install postgresql@16`)
- Database name: `url_shortener`
## Completed
- Installed SQLAlchemy 2.1.3
- Installed psycopg2-binary 2.9.13
- SQLAlchemy was built from source during installation
